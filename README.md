# Многопоточность и параллелизм в Unix/Linux

## Содержание
1. **Задание 1: Кольцо процессов (`fork` + `pipe`)**  
   Создает кольцо из 3-х процессов, обменивающихся сообщениями через каналы. Демонстрирует правильное управление файловыми дескрипторами для предотвращения взаимной блокировки (deadlock).
2. **Задание 2: Мини-system() (`fork` + `exec`)**  
   Собственный "runner", который выполняет команду с аргументами и выводит статус ее завершения.
3. **Задание 3: Параллельная сумма массива (`pthread`)**  
   Вычисляет сумму большого массива целых чисел с помощью 4-х потоков (каждый обрабатывает свою четверть), с последующей сверкой с однопоточным подсчетом.

## Сборка и запуск
Все программы написаны на языке C и компилируются с помощью `gcc`. 
Для примера с потоками обязателен флаг `-pthread`.
